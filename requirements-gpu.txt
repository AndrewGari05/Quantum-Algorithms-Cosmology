# ============================================================================
# GPU EXTRAS
# ============================================================================
# [B-GPU] READ THIS BEFORE INSTALLING.
#
# These packages on their own do NOT enable the GPU. The `qiskit-aer` wheel
# that requirements.txt installs from PyPI is compiled FOR CPU ONLY: putting
# cuQuantum next to it does not turn it into a GPU build. Aer has to be BUILT
# with CUDA support (the GPU wheel published by the Aer project itself, or a
# build with AER_THRUST_BACKEND=CUDA).
#
# Otherwise `--gpu` falls back to CPU. It used to do so SILENTLY — the run
# finished, the numbers came out right, and only the wall-clock time revealed
# that the accelerator had not been used. Now it warns and explains why.
#
# On any new node, check BEFORE launching a long run:
#
#     python cosmo_hpc_runner.py --gpu-check
#
# It will tell you which devices Aer declares, which packages are installed and
# whether nvidia-smi sees a card. Check the qiskit-aer documentation to find out
# which GPU wheel matches version 0.17.x before installing anything: the name
# and availability have changed between versions.
# ============================================================================
